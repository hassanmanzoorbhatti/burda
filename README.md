# KFZ Burda — website design concept

Independent responsive static website concept by Hassan Manzoor. Adapted from the Zahnraum layout, using black/yellow and a Tahoma system font stack.

Source: https://stadler49.wixsite.com/kfz-burda (reviewed 11 October 2026). Service images are website stock motifs, not verified workshop/team photographs. No invented reviews. Opening hours conflict with directories; phone confirmation note included.

Phone/email links only, no fake enquiry submission. No tracking, remote fonts, embeds or browser storage. Noindex. Legal pages describe the independent preview; official business details and image licensing require confirmation before replacing the business website.

Deploy as static site on Vercel; no build or dependencies.
